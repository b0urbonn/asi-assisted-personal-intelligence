## Doc Conventions

Every doc follows the same structure:

```
# Title
> Status · Version · Last updated
## Table of Contents
## 1. Section
## 2. Section
...
```

- **Status values:** `draft` → `review` → `approved` → `living` (updated alongside code)
- **Checkboxes:** `- [ ]` = planned, `- [x]` = done
- **Decisions:** open questions are tracked in each doc's "Open Questions" or "Decisions" section
